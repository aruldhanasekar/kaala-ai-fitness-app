# AI Fitness App – Kaala

Kaala is a command-line fitness app written in Python.
It currently calculates Body Mass Index (BMI) and acts as a simple fitness coach.
The app will be expanded over time to include smarter fitness guidance.

## What Kaala does
- Calculates BMI
- Supports different weight and height units
- Runs in the terminal
- Guides the user through a simple fitness check

## How to run
Python must be installed.

Run:
python coach.py

## Files
- bmi.py: BMI calculation
- coach.py: Kaala, the fitness coach

## Project status
The project is under development.
Only BMI tracking is available at the moment.
